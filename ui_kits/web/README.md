# Web JUMCO / [NOMBRE DEL PRODUCTO]
Cuatro páginas estáticas (Inicio, Sobre nosotros, Noticias, Contacto). Web corporativa de JUMCO; el producto es secundario en HTML + Bootstrap 5 + CSS propio, sin React. Clases propias con guiones bajos; cada banda es un `<section class="banda_*">` independiente, trasladable a un parcial de Twig. Cabecera y pie idénticos en las cuatro páginas.
CSS: `css/layout_general.css` (base, cabecera, pie, botones), `css/banda_noticias.css` (cajas de noticia compartidas), `css/index.css`, `css/interior.css`. Los tokens vienen de `../../styles.css`.
Imágenes: marcadores de posición. Iconos: Font Awesome 6. Botones sin flechas ni iconos. Textos provisionales; sin datos inventados.
